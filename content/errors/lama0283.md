# LAMA0283: Compile-time types can't have a primary constructor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The compile-time type '<Type>' has a primary constructor, which is not supported in compile-time code. Remove the parameter list from the type and declare an explicit constructor instead.` |

## Cause

C# 12 introduced primary constructors for classes and structs: a parameter list placed directly after the type name. Metalama doesn't support primary constructors in compile-time code.

Metalama reports LAMA0283 when a class or struct whose scope is compile-time or run-time-or-compile-time declares a primary constructor. This includes aspects, fabrics, and types marked with `[CompileTime]` or `[RunTimeOrCompileTime]`. Records aren't affected: their primary constructors are supported.
