# LAMA0536: The pull strategy must provide a value for the forwarding constructor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot generate the forwarding constructor '<Forwarder>' because the pull strategy returned '<ReturnedKind>' for the parameter '<IntroducedParameter>'. For a forwarding constructor, the pull strategy must provide a value, for instance with PullAction.UseExpression, and must not return PullAction.None.` |

## Cause

When an aspect introduces a parameter into a constructor with the <xref:Metalama.Framework.Aspects.AdviserExtensions.IntroduceParameter*> method and an overloading strategy like <xref:Metalama.Framework.Advising.ConstructorOverloadingStrategy.ForwardSourceConstructors>, Metalama generates a _forwarding constructor_. This constructor keeps the original signature and calls the modified constructor with `: this(...)`. It must pass a value for the new parameter, and it asks the pull strategy, an <xref:Metalama.Framework.Advising.IPullStrategy>, for this value.

Because the signature of the forwarding constructor is fixed, the pull strategy must return an action that provides a value. Metalama reports LAMA0536 when the strategy returns <xref:Metalama.Framework.Advising.PullAction.None>, which means that no value is passed. In the message, `<ReturnedKind>` is the internal name of the returned action, for example `DoNotPull` for `PullAction.None`.

In the following example, the custom pull strategy of the `AddTimestamp` aspect returns `PullAction.None`.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0536/LAMA0536_Error.cs name="Error"]

## Resolution

Make the pull strategy return an action that provides a value:

* <xref:Metalama.Framework.Advising.PullAction.UseExpression*> or `PullAction.UseConstant` passes an expression or a constant, as shown in the following example.
* <xref:Metalama.Framework.Advising.PullAction.IntroduceParameterAndPull*> adds a parameter to the calling constructors; its `forwarderExpression` argument sets the value passed by the forwarding constructor.

If you don't need a custom strategy, use one of the built-in strategies of the <xref:Metalama.Framework.Advising.PullStrategy> class, for example <xref:Metalama.Framework.Advising.PullStrategy.UseExpression*>.
