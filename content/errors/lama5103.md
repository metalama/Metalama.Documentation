# LAMA5103: The parameter types of the invalidating and cached methods don't match

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Caching |
| **Message** | `The [InvalidateCache] aspect applied to '<InvalidatingMethod>' cannot invalidate '<CachedMethod>': the type of the '<ParameterName>' parameter of the cached method is not compatible with the type of the '<ParameterName>' parameter in the invalidating method.` |

## Cause

To remove a value from the cache, the <xref:Metalama.Patterns.Caching.Aspects.InvalidateCacheAttribute?text=[InvalidateCache]> aspect rebuilds the cache key of the invalidated method from the arguments of the invalidating method. It matches the parameters of both methods by name, then passes the argument of the invalidating method in place of the parameter of the cached method.

Metalama reports LAMA5103 when the type of the parameter `<ParameterName>` of the invalidating method `<InvalidatingMethod>` can't be converted to the type of the parameter of the same name in the cached method `<CachedMethod>`. The check follows the rules of the C# `is` operator: a parameter of the same type, of a derived type, or of a type that implements the expected interface is compatible. A parameter of a base type or of an unrelated type isn't, and neither is a type that requires a numeric or user-defined conversion, such as `int` to `long`.

In the following example, `GetPrice` takes a `string` product identifier, but `UpdatePrice` takes an `int`.

## Resolution

Do one of the following:

* Change the type of the parameter of the invalidating method so that it's the same as the type of the parameter of the cached method, or derived from it, as in the following example.
* If the parameter of the cached method shouldn't be part of the cache key, add the <xref:Metalama.Patterns.Caching.NotCacheKeyAttribute?text=[NotCacheKey]> attribute to it.
* If the methods are too different to be matched, invalidate the cache imperatively by calling the `Invalidate` method of the caching service, converting the arguments yourself.
