# LAMA1015: A call to a partial method without implementation can't be intercepted

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Extensions.Interceptors |
| **Message** | `The <Site> cannot be intercepted because '<Method>' is a partial method without implementation. A source generator that runs after Metalama could implement it, and the call would then run without the interceptor.` |

## Cause

The `Metalama.Extensions.Interceptors` package lets an aspect or a fabric replace the calls to selected methods with calls to another method, called an _interceptor_.

When a partial method has no implementation in the compilation, the C# compiler removes the calls to it. A source generator that runs after Metalama can still provide the implementation. The call would then run without the interceptor, and the behavior of the program would depend on the generator. To avoid this inconsistency, Metalama reports LAMA1015 for every call to such a method that an interception registration selects. It reports the error before it asks the registration for an interceptor, so returning `Skip` doesn't prevent it. In the message, `<Site>` describes the call and `<Method>` is the partial method.

## Resolution

Do one of the following:

* Implement the partial method in the same compilation. In the following example, the method has an implementation, so the call is intercepted.
* Exclude the call from the interception, by selecting another method or by restricting the scope of the registration.
