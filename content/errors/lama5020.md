# LAMA5020: The field of an immutable type must be read-only

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Immutability |
| **Message** | `The '<Field>' field must be read-only because of the [Immutable] aspect.` |

## Cause

The <xref:Metalama.Patterns.Immutability.ImmutableAttribute> aspect declares that the instances of a type can't be modified after construction. Metalama reports LAMA5020 when such a type declares a field without the `readonly` modifier, because any code with access to the field could modify it.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5020/LAMA5020_Error.cs name="Warning"]

## Resolution

Add the `readonly` modifier to the field and assign it only from constructors, as in the following example. If the field must remain writable, the type isn't immutable: remove the `[Immutable]` aspect.
