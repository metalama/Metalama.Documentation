# LAMA0273: A template can only be referenced in a direct call

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The template '<Template>' can only be referenced in a direct call. It cannot be assigned to a delegate, passed as an argument, or called with the '?.' operator.` |

## Cause

A template can call an auxiliary template, and the code generated by the auxiliary template expands at the call site. This expansion happens at compile time, so Metalama must know statically which template is called. That's why the only accepted forms are `Template(...)` and `expression.Template(...)`.

Metalama reports LAMA0273 when a template references an auxiliary template in any other way, for example:

* by assigning the template to a delegate or a variable;
* by passing the template as an argument to a method;
* by calling it with the conditional access operator `?.`.

The `<Template>` placeholder is the referenced template.

## Resolution

Call the auxiliary template directly, as a stand-alone statement. If the call must depend on a condition, put the direct call in a compile-time `if` statement instead of using `?.`.

If you need to pass a template call as a value, for example to let another template decide when to call it, use a <xref:Metalama.Framework.Aspects.TemplateInvocation> and invoke it with <xref:Metalama.Framework.Aspects.meta.InvokeTemplate*?text=meta.InvokeTemplate>.
