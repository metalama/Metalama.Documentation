# LAMA0526: An introduced indexer must have at least one parameter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot introduce the indexer '<Member>' into the type '<TargetType>' because the indexer has no parameter. An indexer must have at least one parameter.` |

## Cause

In C#, an indexer must have at least one parameter. When an aspect introduces an indexer with the <xref:Metalama.Framework.Aspects.AdviserExtensions.IntroduceIndexer*> method, the parameters of the indexer come from the `indices` argument and from the `buildIndexer` delegate.

Metalama reports LAMA0526 when the introduced indexer has no parameter after the `buildIndexer` delegate has run, for instance because the aspect passes an empty list of indices. The error is reported on the target type, and `<Member>` shows the indexer with empty brackets, for example `ProductCatalog.this[]`.

In the following example, the `Indexer` aspect passes an empty list of indices.

## Resolution

Give the indexer at least one parameter:

* Pass at least one `(type, name)` pair in the `indices` argument of `IntroduceIndexer`.
* If the aspect computes the indices from the target type, check that the list isn't empty before calling `IntroduceIndexer`, and skip the introduction or report your own diagnostic when it's empty.
