# LAMA5022: The field or property of a deeply immutable type must be deeply immutable

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Immutability |
| **Message** | `The type of the '<FieldOrProperty>' <DeclarationKind> must be deeply immutable.` |

## Cause

When you apply the <xref:Metalama.Patterns.Immutability.ImmutableAttribute> aspect with the `ImmutabilityKind.Deep` argument, you declare that no object reachable from an instance of the type can be modified. Every instance field and automatic property must therefore be of a deeply immutable type. Metalama reports LAMA5022 when a read-only field, or a get-only or init-only automatic property, has a type that isn't deeply immutable. The first placeholder of the message is the field or property, and the second is its kind: `field` or `property`.

Deeply immutable types include intrinsic types like `int` and `string`, enums, most structs of the `System` namespace, immutable collections whose type arguments are deeply immutable, and types marked with `[Immutable(ImmutabilityKind.Deep)]`. Mutable collections like `List<T>`, interfaces, and types marked only with `[Immutable]` (shallow immutability) aren't deeply immutable.

Writable fields and properties with a setter aren't checked for deep immutability, because they already cause <xref:lama5020> or <xref:lama5021>. The check doesn't run at design time, so the warning appears only when you build the project.

In the following example, the `Items` property of the deeply immutable `Order` class is a `List<string>`.

## Resolution

Do one of the following:

* Change the type of the field or property to a deeply immutable type, for instance an immutable collection, as in the following example.
* If the type is yours and is deeply immutable, mark it with `[Immutable(ImmutabilityKind.Deep)]`. For a type you don't own, use the <xref:Metalama.Patterns.Immutability.Configuration.ImmutabilityConfigurationExtensions.ConfigureImmutability*> fabric method.
* If the type only needs to be shallowly immutable, remove the `ImmutabilityKind.Deep` argument.
