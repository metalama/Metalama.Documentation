# LAMA0108: A compile-time variable can't be set under a run-time condition

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The compile-time variable '<VariableName>' cannot be set here because the assignment is in a block whose execution depends on a run-time condition ('<RunTimeCondition>'), and the variable is not declared in that block. Move the assignment out of this block, or declare the variable inside the block.` |

## Cause

In a T# template, compile-time code runs once, while Metalama generates the target code. Run-time statements such as an `if` with a run-time condition, or a run-time `for`, `foreach`, `while`, `switch`, `catch`, or `finally`, are only emitted into the generated code: whether their body executes is decided later, when the program runs. When Metalama expands the template, it always walks through the body of such a block, so it can't know whether a compile-time assignment in that body should happen.

For this reason, Metalama reports LAMA0108 when, inside a run-time-conditional block, a template modifies a compile-time local variable that's declared outside the block. The modification can be an assignment, a compound assignment like `+=`, an increment or decrement, or passing the variable as an `out` or `ref` argument. The first placeholder of the message is the variable, and the second one is the statement that introduces the run-time condition.

## Resolution

Depending on your intent, do one of the following:

* If the value of the variable depends on run-time data, make it a run-time variable: initialize it without `meta.CompileTime`, for instance with a literal. Metalama then emits the variable and its modifications into the generated code. The following example uses this fix.
* If the assignment doesn't depend on the run-time condition, move it out of the run-time-conditional block.
* If the variable is only used inside the block, declare it inside the block.
* If the condition can be evaluated at compile time, make it a compile-time expression, for example by testing properties of `meta.Target` instead of run-time values, so that the `if` statement becomes compile-time.
