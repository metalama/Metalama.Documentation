# LAMA0202: A multidimensional array can't be converted to a run-time value

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot serialize the compile-time array of type '<Type>' to a run-time value because it has more than one dimension. Use a jagged array instead.` |

## Cause

When a template uses a compile-time array in a run-time context, Metalama generates an array creation expression that contains the converted items. This conversion only supports one-dimensional arrays. Arrays of arrays, also known as _jagged arrays_, are one-dimensional, so they're supported.

Metalama reports LAMA0202 when it expands the template and finds an array with more than one dimension, for instance an `int[,]`. The error is reported on the target declaration of the aspect. In the message, `<Type>` is the CLR name of the array type, for instance `Int32[,]`.

## Resolution

Use a jagged array, for instance `int[][]` instead of `int[,]`, for the compile-time value. In the following example, the helper class builds a jagged array. If the run-time code needs a multidimensional array, convert the jagged array at run time.
