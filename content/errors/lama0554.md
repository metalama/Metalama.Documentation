# LAMA0554: A union must declare at least one case

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<Aspect>' cannot introduce the union '<Union>' because a union declaration must declare at least one case. Call 'AddCase' at least once in the callback that builds the union.` |

## Cause

A C# union is declared by the list of its cases, such as `union Result(int, string);`. The language requires at least one case. When an aspect introduces a union with the `IntroduceUnion` method, it declares the cases by calling `AddCase` in the callback that builds the union.

Metalama reports LAMA0554 when this callback returns without having called `AddCase`. Without this check, the C# compiler would report an error on generated code, which is hard to trace back to the aspect.

In the following example, the aspect introduces the `Result` union without any case.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0554/LAMA0554_Error.cs name="Error"]

## Resolution

Call `AddCase` in the callback for each type that the union can hold. In the following example, the `Result` union has two cases, `int` and `string`.
