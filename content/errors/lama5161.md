# LAMA5161: The members of a child object can't be observed

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Observability |
| **Message** | `The members of '<Type>' cannot be observed because '<Type>' does not implement INotifyPropertyChanged and is not immutable. Implement INotifyPropertyChanged in '<Type>', for example with the [Observable] aspect, or mark '<Type>' as immutable.` |

## Cause

The <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect analyzes the getters of computed properties to find their dependencies. When a getter reads a member of a child object, for example `this.Person.Name`, the aspect subscribes to the `PropertyChanged` event of the child object, here `Person`, to know when `Name` changes.

Metalama reports LAMA5161 when the type of the child object, `<Type>` in the message, doesn't implement `INotifyPropertyChanged` and isn't immutable. The aspect then can't know when the member of the child object changes, so the computed property doesn't raise a notification in this case. It still raises one when the child object itself is replaced. The warning is reported on the reference to the child object in the getter.

In the following example, `DisplayName` depends on `Person.Name`, but `Person` doesn't implement `INotifyPropertyChanged`.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5161/LAMA5161_Error.cs name="Warning"]

## Resolution

Do one of the following:

* Make the type of the child object implement `INotifyPropertyChanged`, for example by applying the `[Observable]` aspect to it, as in the following example.
* If the child object can't change after construction, mark its type as immutable, for example with the <xref:Metalama.Patterns.Immutability.ImmutableAttribute?text=[Immutable]> aspect. The aspect then knows that it doesn't need to observe its members.
* If you accept that the computed property doesn't track changes of the child object, suppress the warning with the <xref:Metalama.Patterns.Observability.SuppressObservabilityWarningsAttribute?text=[SuppressObservabilityWarnings]> attribute.
