# LAMA0256: The dynamic argument must be cast to IExpression

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The dynamic expression '<Expression>' must be explicitly cast to 'IExpression' because it is a dynamic argument of a compile-time method that does not return a dynamic type.` |

## Cause

Some compile-time methods of the Metalama API have a parameter of type `dynamic`, which accepts a run-time expression. A typical example is `WithObject`, which you call on a field, property, or method of the code model to choose the object on which the member is accessed. These methods return a compile-time object, for example an invoker, not a run-time value.

When you pass a `dynamic` expression, such as the <xref:Metalama.Framework.Code.IExpression.Value> property of a parameter, to such a parameter, the template compiler must convert the run-time expression into a compile-time <xref:Metalama.Framework.Code.IExpression> object. Metalama requires you to make this conversion explicit and reports LAMA0256 when it's implicit. The diagnostic isn't reported when the call is used as a statement on its own.

## Resolution

Do one of the following:

* Cast the `dynamic` expression to <xref:Metalama.Framework.Code.IExpression>, as shown in the following example.
* If you already have an object that implements <xref:Metalama.Framework.Code.IExpression>, like the <xref:Metalama.Framework.Code.IParameter> itself, pass this object directly instead of its `Value` property.
