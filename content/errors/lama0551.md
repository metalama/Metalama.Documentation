# LAMA0551: The base type's OnConstructed method requires a constructor accepting InitializationContext

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' targets type '<TargetType>' whose base type '<BaseType>' defines an 'OnConstructed(InitializationContext)' method but has no instance constructor accepting an 'InitializationContext' parameter. The base type must provide such a constructor (and call 'OnConstructed' from it, guarded by 'IsHandled(InitializationSlot.OnConstructed)') so that derived types can pass 'context.Descend(InitializationSlot.OnConstructed)' and skip the base's OnConstructed call.` |

## Cause

When an aspect calls <xref:Metalama.Framework.Aspects.AdviserExtensions.AddInitializer*> with <xref:Metalama.Framework.Advising.InitializerKind.AfterLastInstanceConstructor>, Metalama adds the aspect's code to an `OnConstructed( InitializationContext )` method and calls this method at the end of every constructor of the target type. If a base type already defines a virtual `OnConstructed( InitializationContext )` method, Metalama overrides it in the target type and calls `base.OnConstructed(...)` from the override.

The base constructor must then skip its own call to `OnConstructed`, otherwise the method would run twice: once from the base constructor and once from the derived constructor. To make this possible, the derived constructor passes an <xref:Metalama.Framework.RunTime.Initialization.InitializationContext> to the base constructor, and the base constructor calls `OnConstructed` only if the context doesn't mark it as handled.

Metalama reports LAMA0551 when the type `<BaseType>` that declares the virtual `OnConstructed( InitializationContext )` method has no constructor with an `InitializationContext` parameter. This typically happens when you write the base type by hand, without an aspect.

In the following example, the `Entity` base class defines `OnConstructed`, but its constructor has no `InitializationContext` parameter.

## Resolution

Add an `InitializationContext` parameter to the constructor of the base type, with a `default` value, and call `OnConstructed` from this constructor only when `context.IsHandled( InitializationSlot.OnConstructed )` returns `false`. Metalama then makes the constructors of the derived type pass a context that marks `OnConstructed` as handled.
