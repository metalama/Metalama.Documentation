# LAMA0255: A run-time expression can't be cast to a compile-time type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot cast the run-time expression '<Expression>' to the compile-time type '<Type>'.` |

## Cause

In a T# template, a run-time expression represents code that's evaluated when the program runs, while a value of a compile-time-only type, such as `IParameter` or `IMethod`, exists only while Metalama compiles the code. A cast can't turn one into the other.

Metalama reports LAMA0255 when a template casts an expression whose value is run-time to a compile-time-only type. The most common cause is a confusion between a declaration of the code model and its run-time value: for instance, the <xref:Metalama.Framework.Code.IExpression.Value> property of an `IParameter` represents the value of the parameter at run time, not the parameter itself. A cast to `IExpression` is a different case, reported as LAMA0286.

## Resolution

Read compile-time information from the compile-time code model, for instance from `meta.Target.Parameters`, and use the `Value` property only when you need the run-time value. In the following example, the aspect reads the `IParameter` directly from `meta.Target.Parameters` and logs its name.
