# LAMA0037: The aspect can't be applied to the declaration

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectName>' cannot be applied to the <DeclarationKind> '<Target>' because <Reason>.` |

## Cause

Every aspect can declare _eligibility conditions_ in its `BuildEligibility` method. These conditions describe the declarations to which the aspect can be applied. For instance, an aspect can require the target method to be non-static or to have a non-`void` return type.

Metalama reports LAMA0037 when you apply an aspect to a declaration, typically with a custom attribute, but the declaration doesn't satisfy one of these conditions. The last part of the message explains which condition failed.

In the following example, the `Log` aspect requires an instance method, but it's applied to a static method.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0037/LAMA0037_Error.cs name="Error"]

## Resolution

Depending on your intent, do one of the following:

* Remove the aspect from the declaration.
* Change the declaration so that it satisfies the condition given in the message. In the following example, the method is made non-static.
* If you're the author of the aspect and the condition is too strict, relax the condition in the aspect's `BuildEligibility` method.

When you add aspects with a fabric, use the `Where` method to select only eligible declarations instead of adding aspects to all declarations.
