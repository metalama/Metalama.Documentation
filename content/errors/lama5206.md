# LAMA5206: A required helper member wasn't found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Wpf |
| **Message** | `No <Role> matching <CandidateNames> was found for the <MemberKind> '<Target>'.` |

## Cause

The <xref:Metalama.Patterns.Wpf.CommandAttribute?text=[Command]> and <xref:Metalama.Patterns.Wpf.DependencyPropertyAttribute?text=[DependencyProperty]> aspects look for helper members by name. With the default naming convention, these members are optional: if no `CanSave` member or `OnFooChanged` method exists, the aspect simply works without it.

A helper member becomes required in the following situations, and Metalama reports LAMA5206 on the aspect's target when no member with the expected name exists:

* You set <xref:Metalama.Patterns.Wpf.CommandAttribute.CanExecuteMethod> or <xref:Metalama.Patterns.Wpf.CommandAttribute.CanExecuteProperty> in the `[Command]` attribute.
* You set <xref:Metalama.Patterns.Wpf.DependencyPropertyAttribute.PropertyChangedMethod> or <xref:Metalama.Patterns.Wpf.DependencyPropertyAttribute.ValidateMethod> in the `[DependencyProperty]` attribute.
* A custom naming convention requires the member, for example a <xref:Metalama.Patterns.Wpf.Configuration.CommandNamingConvention> with <xref:Metalama.Patterns.Wpf.Configuration.CommandNamingConvention.CanExecutePatterns>, which makes the can-execute member required unless <xref:Metalama.Patterns.Wpf.Configuration.CommandNamingConvention.IsCanExecuteRequired> is `false`.

The aspect isn't applied to the target. In the message, `<Role>` is the role of the missing member, for example `property-changed method`, `<CandidateNames>` is the expected name or pattern, `<MemberKind>` is `command` or `dependency property`, and `<Target>` is the aspect's target. For commands, `<Role>` always reads `can-execute method or can-execute property`, even when you set only one of the two attribute properties.

## Resolution

* Check the spelling of the name in the attribute. The names are case-sensitive. Use `nameof`, for example `[Command( CanExecuteProperty = nameof(IsSaveEnabled) )]`, so that the compiler checks the name.
* Check that the member has the right kind: `CanExecuteMethod` only looks for methods, and `CanExecuteProperty` only looks for properties. The member must be declared in the type of the aspect's target.
* Add the missing member if it doesn't exist yet.
* If the member is optional in your design, remove the explicit name from the attribute, or set `IsCanExecuteRequired = false` in your custom naming convention.
