# LAMA0904: The usage validation attribute doesn't define any scope

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Extensions.Architecture |
| **Message** | `The '<AttributeName>' custom attribute does not define any scope. Set at least one of the following properties: Namespaces, NamespaceOfTypes, Types, TypeNames, CurrentNamespace, or CurrentAssembly.` |

## Cause

The usage validation attributes <xref:Metalama.Extensions.Architecture.Aspects.CanOnlyBeUsedFromAttribute>, <xref:Metalama.Extensions.Architecture.Aspects.CannotBeUsedFromAttribute>, <xref:Metalama.Extensions.Architecture.Aspects.InternalsCanOnlyBeUsedFromAttribute>, and <xref:Metalama.Extensions.Architecture.Aspects.InternalsCannotBeUsedFromAttribute> restrict the code that can use a type or member. The scope of the rule, that is, the code that's allowed or forbidden, is defined by the following properties:

* <xref:Metalama.Extensions.Architecture.Aspects.BaseUsageValidationAttribute.Namespaces>
* <xref:Metalama.Extensions.Architecture.Aspects.BaseUsageValidationAttribute.NamespaceOfTypes>
* <xref:Metalama.Extensions.Architecture.Aspects.BaseUsageValidationAttribute.Types>
* `TypeNames`
* `CurrentNamespace`
* `CurrentAssembly`

Metalama reports LAMA0904 when none of these properties is set. Other properties, such as <xref:Metalama.Extensions.Architecture.Aspects.BaseUsageValidationAttribute.Description>, `ReferenceKinds`, or `ExclusionPredicateType`, don't define a scope, so setting only these properties still causes the error. When this error is reported, the attribute doesn't validate anything. In the message, `<AttributeName>` is the name of the attribute class, for example `CanOnlyBeUsedFromAttribute`.

In the following example, the `[CanOnlyBeUsedFrom]` attribute only sets the `Description` property.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0904/LAMA0904_Error.cs name="Error"]

## Resolution

Set at least one of the scope properties to define which code is allowed (for `[CanOnlyBeUsedFrom]`) or forbidden (for `[CannotBeUsedFrom]`) to use the declaration. If you don't want to restrict the usage of the declaration, remove the attribute.

In the following example, the `Types` property specifies that only the `OrderFactory` class can use the `Order` class.
