# LAMA5162: The method called by a computed property isn't known to be constant

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Observability |
| **Message** | `The '<Member>' <Kind> cannot be observed because it is not known to be constant: it is an instance method of a type that is not immutable, or it has a parameter of a type that is not immutable. If the <Kind> always returns the same value for the same arguments, mark it with [Constant] or call ConfigureObservability via a fabric.` |

## Cause

The <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect analyzes the getter of each computed property to find the fields and properties it depends on. When the getter calls a method, the aspect only tracks the arguments of the call. This is correct only if the method is _constant_, that is, if it always returns the same value for the same arguments.

A method is considered constant when it's marked with <xref:Metalama.Patterns.Observability.ConstantAttribute?text=[Constant]> or configured with an observability contract, when it's a `void` method without `out` or `ref` parameters, or when all its inputs are immutable: it's static or belongs to an immutable type, and all its parameters are of immutable types.

Metalama reports LAMA5162 when a computed property calls a method that doesn't meet any of these conditions. The aspect still generates code, but the property isn't notified when the state read by the method changes. In the message, `<Member>` is the method and `<Kind>` is the kind of symbol, `method`.

## Resolution

Do one of the following:

* If the result of the method depends only on its arguments, mark the method with <xref:Metalama.Patterns.Observability.ConstantAttribute?text=[Constant]>, as in the following example.
* To mark many methods as constant, for example all methods of a helper class, call <xref:Metalama.Patterns.Observability.Configuration.ObservabilityExtensions.ConfigureObservability*> from a fabric and set the observability contract to `ObservabilityContract.Constant`.
* If the method doesn't use instance state, make it `static`. A static method whose parameters are all of immutable types is considered constant automatically.
* If the method reads mutable state, pass this state as arguments, or move the logic into the getter, so that the aspect can track it.

Don't mark a method as constant when its result depends on mutable state: the property wouldn't be notified when this state changes.
