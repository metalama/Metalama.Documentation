# LAMA0505: An aspect can't introduce an instance member into a static class

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot introduce instance member '<Member>' into type '<TargetType>' because the type is static.` |

## Cause

In C#, a static class can only contain static members. Metalama reports LAMA0505 when an aspect introduces a member that isn't static into a static class.

Whether an introduced member is static depends on the introduction scope, set by the `scope` parameter of methods like <xref:Metalama.Framework.Aspects.AdviserExtensions.IntroduceMethod*> or by the <xref:Metalama.Framework.Aspects.IntroduceAttribute.Scope> property. With the default scope, the introduced member is static only when the template is static. Therefore, an aspect that uses an instance template and the default scope introduces an instance member, even when the target class is static.

## Resolution

Depending on your intent, do one of the following:

* Introduce a static member. Pass <xref:Metalama.Framework.Aspects.IntroductionScope.Static?displayProperty=nameWithType> as the scope, or make the template static. If the aspect can be applied to both static and non-static classes, choose the scope according to the `IsStatic` property of the target type.
* Make the target class non-static, if the introduced member really needs an instance.
* If you're the author of the aspect and it doesn't support static classes, make the aspect ineligible for static types in its `BuildEligibility` method, so that users get a clearer error when they apply it to a static class.
