# LAMA0271: A template can't be an extension method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The template '<Template>' cannot be an extension method. To introduce an extension method, mark the first parameter of the template with the [This] attribute, or set the IParameterBuilder.IsThis property programmatically.` |

## Cause

Metalama reports LAMA0271 when a method marked as a template, for instance with `[Template]` or `[Introduce]`, is a C# extension method, that is, when its first parameter has the `this` modifier. Templates don't support the `this` modifier on their parameters.

You typically get this error when you want an aspect to introduce an extension method into a static class. The `this` modifier doesn't belong in the template, because the template isn't the extension method: it only describes the method that Metalama introduces into the target class.

C# allows extension methods only in top-level static classes, and such a class can't be an aspect, a fabric, or a type implementing `ITemplateProvider`. Therefore, Metalama always reports `LAMA0274` together with LAMA0271, as in the following example, where the `PrintDetails` template is an extension method of a static class.

## Resolution

Remove the `this` modifier from the first parameter of the template, and move the template to an aspect, a fabric, or a class implementing <xref:Metalama.Framework.Aspects.ITemplateProvider>. Then, to make the introduced method an extension method, do one of the following:

* Mark the first parameter of the template with the <xref:Metalama.Framework.Aspects.ThisAttribute> attribute. As C# requires for extension methods, the introduced method must be static, and the target type must be a static class.
* When you introduce the method programmatically, set the <xref:Metalama.Framework.Code.DeclarationBuilders.IParameterBuilder.IsThis> property of its first parameter to `true` in the `buildMethod` delegate.

In the following example, the template is moved to an aspect, its parameter is marked with the `[This]` attribute, and the aspect is applied to the static class that receives the extension method.
