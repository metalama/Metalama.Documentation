# LAMA0269: An anonymous type is used in both run-time and compile-time code

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The anonymous type '<AnonymousType>' cannot be used in both run-time and compile-time code in the same template. Change the property names or types of one of the anonymous objects, or use a named type instead.` |

## Cause

In a T# template, an anonymous object is normally _run-time_: Metalama copies the `new { ... }` expression into the target code. It's _compile-time_ only when it appears in a compile-time context, for instance in the argument of `meta.CompileTime(...)` or in a lambda passed to a compile-time LINQ method.

The C# compiler gives the same anonymous type to all anonymous objects of a compilation that have the same property names, in the same order, with the same types. Metalama assigns a single scope to each anonymous type of a template, so it reports LAMA0269 when it finds the same anonymous type created once in run-time code and once in compile-time code. The `<AnonymousType>` placeholder shows the anonymous type, for instance `<anonymous type: string Name>`.

## Resolution

Make sure that the run-time and the compile-time anonymous objects have different anonymous types:

* Rename a property of one of the anonymous objects, or change its type, as in the following example.
* Use a named type instead of a compile-time anonymous object, for instance a class or a record marked with `[CompileTime]`.
