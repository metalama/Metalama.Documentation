# LAMA0907: The exclusion predicate type is invalid

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Extensions.Architecture |
| **Message** | `The type assigned to the ExclusionPredicateType property must be derived from ReferencePredicate.` |

## Cause

The usage validation attributes, such as <xref:Metalama.Extensions.Architecture.Aspects.CanOnlyBeUsedFromAttribute> and <xref:Metalama.Extensions.Architecture.Aspects.CannotBeUsedFromAttribute>, and the <xref:Metalama.Extensions.Architecture.Aspects.DerivedTypesMustRespectRegexNamingConventionAttribute> attribute have an <xref:Metalama.Extensions.Architecture.Aspects.BaseUsageValidationAttribute.ExclusionPredicateType> property. It lets you exclude some references from the rule with a custom predicate: Metalama instantiates the given type and doesn't report any violation for the references that match the predicate.

To be instantiated, the type must be derived from <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate>. Metalama reports LAMA0907 on the target of the attribute when this isn't the case. The attribute is then skipped: although LAMA0907 is only a warning, the whole architecture rule isn't enforced.

If the type is derived from <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate> but doesn't have the required constructor, Metalama reports <xref:lama0908?text=LAMA0908> instead.

In the following example, the `ExcludeTestTypesPredicate` class doesn't derive from <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate>.

## Resolution

Make the exclusion predicate a valid reference predicate:

1. Derive the class from <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate> and mark it with <xref:Metalama.Framework.Aspects.CompileTimeAttribute?text=[CompileTime]>.
2. Add a public constructor that accepts a <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicateBuilder> and passes it to the base constructor.
3. Implement the <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate.IsMatchCore*?text=IsMatchCore> and <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate.GetGranularity?text=GetGranularity> methods.

In the following example, the predicate excludes the references from types whose name ends with `Tests`, so `OrderTests` can use the `Order` class.
