# LAMA0267: A template can't convert an extension method group to a delegate

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Converting the extension method '<Method>' to a delegate using a method group conversion is not supported in templates. Use a lambda expression that invokes the method instead.` |

## Cause

When a template invokes an extension method on a run-time expression, for instance `items.First()`, the template compiler rewrites the call as a call to the static method that declares it, for instance `Enumerable.First( items )`. This rewriting requires an invocation.

C# also lets you convert an extension method to a delegate without invoking it, using a _method group conversion_, for instance `Func<string> f = items.First`. The template compiler can't rewrite this syntax, so Metalama reports LAMA0267. In the message, `<Method>` is the extension method, as bound to its receiver.

## Resolution

Use a lambda expression that invokes the extension method, for instance `() => items.First()`. Alternatively, when the delegate type has a parameter for the receiver, convert the static method itself, without a receiver, for instance `Enumerable.First<string>`.
