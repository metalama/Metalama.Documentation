# LAMA0221: The this keyword can't be used as a run-time expression

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot use 'this' in expression '<Expression>' because a run-time expression is expected, and 'this' in a template is a compile-time keyword. Use 'meta.This' instead.` |

## Cause

In a T# template, the `this` keyword refers to the instance of the aspect or template provider, which exists only at compile time. It doesn't refer to the object whose code the template generates. You can use `this` to access compile-time members of the aspect, but you can't use it as a value in the generated code.

Metalama reports LAMA0221 when a template uses `this` alone where a run-time expression is expected, for instance as an argument of a run-time method. In the message, `<Expression>` is the expression that contains `this`.

In the following example, the template passes `this` to the run-time `AuditLog.Record` method, intending to pass the target object.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0221/LAMA0221_Error.cs name="Error"]

## Resolution

Replace `this` with <xref:Metalama.Framework.Aspects.meta.This?text=meta.This>, which represents the `this` expression of the target code. `meta.This` is only available when the target member isn't static.
