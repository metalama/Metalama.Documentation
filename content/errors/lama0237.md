# LAMA0237: An abstract template property can't have a run-time-only type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The template property '<Property>' cannot be abstract because its type or the type of one of its parameters is run-time-only. Make the template property virtual and give it a default implementation.` |

## Cause

When Metalama builds the compile-time assembly of your project, it compiles every template into compile-time code and removes the template's original declaration. An abstract template has no body to compile, so Metalama keeps its declaration as is in the compile-time assembly. This is possible only if every type in the declaration can be used at compile time. Types defined in your project are run-time-only unless you mark them otherwise, and the compile-time assembly can't reference them.

Metalama reports LAMA0237 when an aspect declares an abstract template property, for instance an abstract property with the <xref:Metalama.Framework.Aspects.IntroduceAttribute> or <xref:Metalama.Framework.Aspects.TemplateAttribute> attribute, and the property type or one of the indexer parameter types is run-time-only. This typically happens in a base aspect that expects derived aspects to provide the implementation of an introduced property.

In the following example, the abstract `Clock` aspect expects derived aspects to implement the introduced `Clock` property, but the property type, `IClock`, is a run-time-only interface defined in the project.

## Resolution

Depending on your intent, do one of the following:

* Make the template property `virtual` instead of `abstract` and give it a default implementation. Derived aspects can still override it. The following example uses this fix.
* If the type can be used at compile time, mark it with the <xref:Metalama.Framework.Aspects.RunTimeOrCompileTimeAttribute> attribute. The type is then also included in the compile-time assembly.
* Change the property type to a type that can be used at compile time, for instance a .NET type.
