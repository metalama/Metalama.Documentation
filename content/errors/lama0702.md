# LAMA0702: No registered dependency injection framework can handle the dependency

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Extensions.DependencyInjection |
| **Message** | `None of the registered dependency injection frameworks can handle the dependency '<DependencyType>' in type '<TargetType>'. Note that the default framework does not support static dependencies.` |

## Cause

The <xref:Metalama.Extensions.DependencyInjection.DependencyAttribute> aspect, the <xref:Metalama.Extensions.DependencyInjection.IntroduceDependencyAttribute> advice, and the `IntroduceDependency` method delegate the code generation to the dependency injection frameworks registered for the project. Before choosing a framework, Metalama asks each registered framework whether it can handle the dependency by calling its <xref:Metalama.Extensions.DependencyInjection.Implementation.IDependencyInjectionFramework.CanHandleDependency*> method.

Metalama reports LAMA0702 when at least one framework is registered but all of them refuse the dependency. In the message, `<DependencyType>` is the type of the dependency and `<TargetType>` is the type into which the dependency must be introduced.

With the built-in frameworks, the usual cause is a static dependency: <xref:Metalama.Extensions.DependencyInjection.Implementation.DefaultDependencyInjectionFramework> pulls dependencies from the constructor, so it only accepts instance fields and properties, and `LoggerDependencyInjectionFramework` only accepts `ILogger` dependencies. A dependency is static when the field or property marked with `[Dependency]` or `[IntroduceDependency]` is static. A custom framework can refuse a dependency for its own reasons.

## Resolution

Depending on the cause, do one of the following:

* Make the field or property non-static, as in the following example.
* If you use a custom framework, check the conditions of its `CanHandleDependency` method, or register a framework that supports this kind of dependency with the <xref:Metalama.Extensions.DependencyInjection.DependencyInjectionOptionsBuilder.RegisterFramework*> method.
