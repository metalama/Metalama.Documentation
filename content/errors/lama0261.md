# LAMA0261: A declaration can have only one template or advice attribute

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Only one template or advice attribute is allowed on a declaration, the member it overrides, and its containing property or event, but '<Attribute>' is applied to '<Declaration>' and '<OtherAttribute>' is applied to '<OtherDeclaration>'.` |

## Cause

Attributes such as <xref:Metalama.Framework.Aspects.TemplateAttribute> and <xref:Metalama.Framework.Aspects.IntroduceAttribute> mark a member of an aspect as a template and tell Metalama how to use it. An advice attribute like `[Introduce]` already makes the member a template, so the two can't be combined.

Metalama reports LAMA0261 when it finds more than one such attribute for the same member. It considers the attributes of the member itself and also:

* the attributes of the member it overrides, for instance the `[Template]` attribute of `OverrideMethodAspect.OverrideMethod`;
* for an accessor, the attributes of the containing property or event.

In the message, `<Declaration>` and `<OtherDeclaration>` are the declarations that carry the attributes `<Attribute>` and `<OtherAttribute>`.

In the following example, the `OverrideMethod` method of the `Log` aspect has the `[Template]` attribute, although the method it overrides, `OverrideMethodAspect.OverrideMethod`, already has it.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0261/LAMA0261_Error.cs name="Error"]

## Resolution

Keep only one attribute:

* When you override a template method of a base class, such as `OverrideMethod`, don't add a template or advice attribute to the override: it inherits the attribute of the base method, as in the following example.
* To introduce a member into the target type, use `[Introduce]` alone, without `[Template]`.
* To use a member as a template that you pass to an advice method, use `[Template]` alone, without an advice attribute.
* Don't add an attribute to an accessor if the containing property or event already has one.
