# LAMA0223: The Proceed variant doesn't match the return type of the method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot use 'meta.<MethodName>()' in '<TargetDeclaration>' because the return type of '<TargetDeclaration>' is not compatible with 'meta.<MethodName>()'. Use 'meta.Proceed()', which supports any return type.` |

## Cause

Besides `meta.Proceed()`, which works with any method, the `meta` API offers specialized variants that expose the result of the overridden method with a more specific type, so that templates can use `await`, `yield`, or `foreach` on it. Each variant requires a compatible return type of the target method:

* `meta.ProceedAsync()` requires an awaitable type, such as `Task`, `Task<T>`, or `ValueTask<T>`, or `void`.
* `meta.ProceedEnumerable()` requires `IEnumerable` or `IEnumerable<T>`, and `meta.ProceedEnumerator()` requires `IEnumerator` or `IEnumerator<T>`.
* `meta.ProceedAsyncEnumerable()` requires `IAsyncEnumerable<T>`, and `meta.ProceedAsyncEnumerator()` requires `IAsyncEnumerator<T>`.

Metalama checks this condition when it expands the template for a specific target method, and reports LAMA0223 on the target method when the condition isn't met. The first placeholder of the message is the name of the Proceed variant, and the second one is the target method. The error typically happens when an aspect designed for async or iterator methods is applied to a method of another kind.

## Resolution

Depending on your intent, do one of the following:

* Use `meta.Proceed()`, which adapts to the return type of the target method. The following example uses this fix.
* Move the code that needs the specialized variant to the specialized template of <xref:Metalama.Framework.Aspects.OverrideMethodAspect>, for instance `OverrideAsyncMethod` or `OverrideEnumerableMethod`. Metalama selects these templates only for compatible methods.
* If the aspect only makes sense for some return types, add an eligibility condition so that it can't be applied to other methods.
