# LAMA5112: The [Cache] aspect can be applied at most once to a method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Caching |
| **Message** | `The [Cache] aspect can be applied at most once to a method.` |

## Cause

A method can be cached only once. Metalama reports LAMA5112 on a method when the <xref:Metalama.Patterns.Caching.Aspects.CacheAttribute?text=[Cache]> aspect is added to it several times, for instance with a custom attribute and with a fabric, or with two fabrics. The aspect isn't applied.

In the following example, `GetPrice` has the `[Cache]` attribute, and a type fabric adds the same aspect to the same method.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5112/LAMA5112_Error.cs name="Error"]

## Resolution

Remove the duplicate: keep either the custom attribute or the code that adds the aspect, such as the fabric.

In the following example, the fabric adds the aspect to `GetStock` only, so each method is cached once.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5112/LAMA5112_Fixed.cs name="Fixed"]
