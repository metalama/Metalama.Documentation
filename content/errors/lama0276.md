# LAMA0276: A called template can't have run-time type parameters

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The called template '<Template>' has a run-time type parameter. The type parameters of a called template must be marked with [CompileTime].` |

## Cause

When a template calls an auxiliary template, Metalama expands the auxiliary template at the call site during compilation. To do this with a generic auxiliary template, Metalama must bind each type parameter to a known type at compile time, so the type parameters of the called template must be compile-time type parameters.

Metalama reports LAMA0276 when a template directly calls a generic auxiliary template that has at least one run-time type parameter, that is, a type parameter that isn't marked with <xref:Metalama.Framework.Aspects.CompileTimeAttribute?text=[CompileTime]>. This also happens when a base template marks its type parameters with `[CompileTime]` but the overriding template in a derived aspect doesn't. The `<Template>` placeholder is the called template.
