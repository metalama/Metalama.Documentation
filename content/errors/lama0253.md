# LAMA0253: A compile-time-only value can't be passed to a run-time method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Compile-time-only type '<Type>' cannot be used in the invocation of run-time method '<Method>'.` |

## Cause

Some types exist only at compile time, for instance the types of the code model like `IMethod`, `IParameter`, or `INamedType`, and the types marked with `[CompileTime]`. Their values describe the code being compiled and don't exist when the program runs.

When a template calls a run-time method, Metalama emits the call into the target code, so each argument must be a value that run-time code can receive. Metalama reports LAMA0253 when the type of an argument is compile-time-only. The first placeholder of the message is the type of the argument, and the second one is the invoked method, as written in the template.

In the following example, the aspect passes `meta.Target.Method`, an `IMethod`, to the run-time `AuditLog.Write` method.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0253/LAMA0253_Error.cs name="Error"]

## Resolution

Pass a run-time value derived from the compile-time object instead of the object itself:

* To pass a description of the declaration, use a string, for instance its `Name` property, as in the following example. Metalama evaluates the expression at compile time and emits the resulting string literal.
* To pass the run-time value of a parameter, field, or property, use its `Value` property, for instance `meta.Target.Parameters[0].Value`.
* To pass a reflection object, use a conversion method of the code model, such as `ToMethodInfo()` or `ToType()`.
