# LAMA0535: A partial member can't be introduced into a non-partial type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot introduce the partial member '<Member>' into the type '<TargetType>' because the type is not partial. Add the partial modifier to the type.` |

## Cause

An aspect introduces a partial member when the template sets the <xref:Metalama.Framework.Aspects.TemplateAttribute.IsPartial> property to `true`. Partial members are typically extension points: the aspect declares a partial method, and you can implement it in your own part of the class.

In C#, only a partial type can contain partial members. Metalama reports LAMA0535 when the target type of the introduction isn't declared with the `partial` modifier.

In the following example, the `InitializationHook` aspect introduces a partial `OnInitialized` method into a class that isn't partial.

## Resolution

Add the `partial` modifier to the target type, as shown in the following example. It's good practice to mark all classes that receive introduced members as `partial` anyway, because it lets the IDE see the introduced members at design time.

If you're the author of the aspect and the member doesn't need to be partial, remove `IsPartial = true` from the template.
