# LAMA5164: The computed property reads a field that can't be observed

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Observability |
| **Message** | `The '<Field>' field cannot be observed: only private instance fields, constants, and read-only fields of immutable types are supported. Consider replacing the field with a property, or making it private.` |

## Cause

The <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect analyzes the getter of each computed property to find the fields and properties it depends on. It supports only the following fields:

* private instance fields,
* constants,
* read-only fields of an immutable type, such as `string`, `int`, or a type marked as immutable. For details, see <xref:immutability>.

Metalama reports LAMA5164 when a computed property reads any other field, for example a public, protected, or internal field, or a mutable static field. Code of other classes can change such a field without raising a notification, so the computed property wouldn't be notified. In the message, `<Field>` is the field.

In the following example, `Total` reads the public field `UnitPrice`.

## Resolution

Do one of the following:

* Replace the field with an auto-property, as in the following example. The aspect then raises a notification when the property changes.
* Make the field `private`, and expose it through a property if other classes need it.
* If the field never changes, make it `readonly` or `const`, provided its type is immutable.
