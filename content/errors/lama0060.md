# LAMA0060: A template can't return a reference

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `'<Member>' cannot be used as a template because it returns 'ref'. This feature is not yet supported.` |

## Cause

Metalama doesn't support templates that return by reference. When it loads an aspect class, it reports LAMA0060 for every template member, for instance a member marked with `[Introduce]` or `[Template]`, that's a method returning `ref` or `ref readonly`, or a property of a `ref` type. In the message, `<Member>` is the template member.

In the following example, the `Counter` aspect introduces a `Count` property that returns a reference to the counter field, so that callers can increment it.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0060/LAMA0060_Error.cs name="Error"]

## Resolution

Change the template so that it returns a value instead of a reference. If callers need to modify the underlying field, introduce a setter or a method that performs the modification. In the following example, the aspect introduces a read-only `Count` property and an `Increment` method.
