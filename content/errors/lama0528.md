# LAMA0528: An existing member must be public to implement an interface member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot override the member '<Member>' to implement an interface member because '<Member>' is not public. Make '<Member>' public, or implement the interface member explicitly.` |

## Cause

When an aspect implements an interface with the <xref:Metalama.Framework.Aspects.AdviserExtensions.ImplementInterface*> method, it provides each interface member with a template marked with <xref:Metalama.Framework.Aspects.InterfaceMemberAttribute?text=[InterfaceMember]>. By default, Metalama creates an implicit implementation, that is, a public member of the target type.

If the target type already has a method, property, or event with the same name and signature as the interface member, and the aspect passes `OverrideStrategy.Override` as the `whenExists` argument, Metalama doesn't introduce a new member. Instead, it overrides the existing member with the template, and this member becomes the implementation of the interface member. An implicit interface implementation must be public, so Metalama reports LAMA0528 when the existing member is private, protected, or internal. In the message, `<Member>` is the existing member of the target type.

In the following example, the `Disposable` aspect implements `IDisposable`, but the `Dispose` method of the target class is private because it has no access modifier.

## Resolution

Do one of the following:

* Make the existing member public, so that Metalama can override it and use it as the implementation of the interface member. The following example shows this fix.
* If the existing member must stay non-public, set the <xref:Metalama.Framework.Aspects.InterfaceMemberAttribute.IsExplicit> property of the `[InterfaceMember]` attribute to `true`. Metalama then introduces an explicit interface implementation and leaves the existing member unchanged.
* Rename the existing member if it isn't meant to implement the interface.
