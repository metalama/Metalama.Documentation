# LAMA0246: A local function in a template can't use dynamic in its signature

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The return type or a parameter type of a local function in a template cannot be dynamic. Use a specific type, for instance 'object', instead.` |

## Cause

In a T# template, `dynamic` stands for a type that Metalama resolves when it expands the template, for instance the return type of the target method. A local function declared in a template is copied to the target code, but Metalama doesn't support `dynamic` in its signature.

Metalama reports LAMA0246 when `dynamic` appears in the return type or in a parameter type of a local function declared in a template. The body of the local function can still use `dynamic` expressions, like `meta.Proceed()`.

## Resolution

Use a specific type in the signature of the local function:

* Use `object?` when the local function must accept or return values of any type, as in the following example.
* Use the actual type when the template is designed for a specific return type or parameter type, for instance `bool`.
