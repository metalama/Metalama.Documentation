# LAMA5156: The OnPropertyChanged(string) method is missing

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Observability |
| **Message** | `Class '<Class>' implements INotifyPropertyChanged but neither defines nor inherits a method with the signature 'protected void OnPropertyChanged(string)', which the [Observable] aspect requires to raise notifications. The method name can also be NotifyOfPropertyChange or RaisePropertyChanged.` |

## Cause

When you apply the <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect to a class that already implements the `PropertyChanged` event, typically because it derives from a base view-model class, the aspect doesn't introduce its own event. Instead, it relies on two methods of the existing implementation:

* a non-static `public` or `protected` method returning `void` with a single `string` parameter, which the aspect calls to _raise_ notifications;
* a `virtual` method taking a `string` or a `PropertyChangedEventArgs`, which the aspect overrides to _react_ to notifications raised by the base class.

These methods can be named `OnPropertyChanged`, `NotifyOfPropertyChange`, or `RaisePropertyChanged`, and they can be inherited.

Metalama reports LAMA5156 when the class has the overridable method but not the method taking a `string`. When the overridable method is missing too, Metalama reports LAMA5150 instead.

In the following example, the base class only provides `OnPropertyChanged( PropertyChangedEventArgs )`.

## Resolution

Add a method with the signature `protected void OnPropertyChanged( string propertyName )` to the class or to its base class. It can simply call the existing method, as in the following example.

Alternatively, change the parameter of the existing `virtual` method to `string`: a single `protected virtual void OnPropertyChanged( string propertyName )` method satisfies both requirements.
