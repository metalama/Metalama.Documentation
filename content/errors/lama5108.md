# LAMA5108: The cached method is invalidated by another method

| | |
|---|---|
| **Severity** | Info |
| **Reported by** | Metalama.Patterns.Caching |
| **Message** | `This method is invalidated by <InvalidatingMethod>.` |

## Cause

When you apply the <xref:Metalama.Patterns.Caching.Aspects.InvalidateCacheAttribute> aspect to a method, this method removes the results of one or more methods cached with the <xref:Metalama.Patterns.Caching.Aspects.CacheAttribute> aspect from the cache. LAMA5108 is designed to annotate the _cached_ method with the name of the method that invalidates it, `<InvalidatingMethod>`, so that you can navigate between the two methods in the IDE. Its counterpart, LAMA5109, annotates the invalidating method.

The current version of Metalama.Patterns.Caching defines this diagnostic but doesn't report it: the code that produces this annotation is disabled until Metalama supports this kind of annotation. Because Metalama never reports this diagnostic, the article has no example.

## Resolution

No action is required. LAMA5108 is informational and doesn't indicate a problem.

To find the methods that invalidate a cached method, search for the name of the cached method in the arguments of the `[InvalidateCache]` attributes.
