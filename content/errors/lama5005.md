# LAMA5005: Invariant suspension is redundant on a type without invariants

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Contracts |
| **Message** | `The [SuspendInvariantsAttribute] aspect on method '<Method>' is redundant because the type '<Type>' does not contain any invariants.` |

## Cause

The <xref:Metalama.Patterns.Contracts.SuspendInvariantsAttribute?text=[SuspendInvariants]> aspect suspends the verification of the invariants of an object while the target method executes. Invariants are the methods of the type, or of its base types, marked with <xref:Metalama.Patterns.Contracts.InvariantAttribute?text=[Invariant]>.

Metalama reports LAMA5005 when invariant suspension is enabled through the <xref:Metalama.Patterns.Contracts.ContractOptions.IsInvariantSuspensionSupported> option, but the declaring type of the method has no invariant. The aspect would have no effect, so Metalama ignores it and leaves the method unchanged.

In the following example, the fabric enables invariant suspension, but the `Account` class doesn't declare any `[Invariant]` method.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5005/LAMA5005_Error.cs name="Warning"]

## Resolution

Depending on your intent, do one of the following:

* If the type should verify invariants, add the missing method marked with `[Invariant]`, as in the following example.
* If the type doesn't need invariants, remove the `[SuspendInvariants]` attribute from the method.
