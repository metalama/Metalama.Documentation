# LAMA0232: A template uses a C# feature that's too recent

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Template code must be compatible with C# <LanguageVersion>, but this syntax requires a later version of C#.` |

## Cause

When Metalama compiles a T# template, it checks that every syntax element of the template is available in the _template language version_. The placeholder of the message is this version. Metalama determines it as follows:

* If the aspect project defines the `MetalamaTemplateLanguageVersion` MSBuild property, its value is the template language version. Aspect library authors set this property so that their templates can be used in projects built with an older version of C#.
* Otherwise, the template language version is the `LangVersion` of the aspect project, limited to the highest version supported by the .NET SDK used for the build.

Metalama reports LAMA0232 on each syntax element of a template that requires a later version of C#, for instance a raw string literal (C# 11) in a template of a project where `MetalamaTemplateLanguageVersion` is `10.0`. This check applies to the code of templates, not to other compile-time code such as `BuildAspect`.

This diagnostic depends on MSBuild properties of the project, so it can't be shown in an example.

## Resolution

Depending on your intent, do one of the following:

* Rewrite the reported code using only features of the C# version given in the message. For instance, replace a raw string literal with a regular or verbatim string literal.
* If your templates don't need to be used by projects built with an older version of C#, raise or remove the `MetalamaTemplateLanguageVersion` property in the aspect project:

  ```xml
  <PropertyGroup>
    <MetalamaTemplateLanguageVersion>12.0</MetalamaTemplateLanguageVersion>
  </PropertyGroup>
  ```

* If the property isn't set, check the `LangVersion` property of the aspect project and the version of the .NET SDK used for the build, for instance in `global.json`.
