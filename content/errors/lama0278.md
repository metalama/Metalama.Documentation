# LAMA0278: An aspect can't be a struct

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<Aspect>' cannot be a value type. Declare it as a class.` |

## Cause

An aspect is a type that implements the <xref:Metalama.Framework.Aspects.IAspect> interface. Metalama creates and manages aspect instances as objects, and the APIs that add aspects, such as `AddAspect`, accept only reference types. For this reason, an aspect must be a class.

Metalama reports LAMA0278 when a struct or a record struct implements <xref:Metalama.Framework.Aspects.IAspect> or one of its generic variants.

## Resolution

Declare the aspect as a class. In the following example, the aspect is a class, so a fabric can add it to the methods of `Calculator`.
