# LAMA0025: The template name doesn't match any member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The type '<AspectType>' does not contain any template member named '<MethodName>'. Check the template name, for instance by using the 'nameof' operator.` |

## Cause

When you add advice programmatically, for instance in the `BuildAspect` method, you identify the template by its name, as a string. Metalama then looks for a member of that name in the aspect class, or in the template provider class.

Metalama reports LAMA0025 when the class, `<AspectType>` in the message, has no member named `<MethodName>`. This typically happens when the string contains a typo, or when the template was renamed but the string wasn't updated. Metalama also reports this error when a template invoked by name from another template doesn't exist. The error is reported on the target declaration of the aspect.

In the following example, the aspect passes `"LogTemplate"` to the `Override` method, but the template is named `OverrideTemplate`.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0025/LAMA0025_Error.cs name="Error"]

## Resolution

Pass the name of an existing template member. To avoid this error in the future, use the `nameof` operator instead of a string literal, so that the C# compiler checks the name and updates it when you rename the template.
