# LAMA1014: The interceptor returned an invalid result

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Extensions.Interceptors |
| **Message** | `The <Source> returned an invalid result for the <Site>. <Detail>` |

## Cause

The `Metalama.Extensions.Interceptors` package lets an aspect or a fabric replace the calls to selected methods with calls to another method, called an _interceptor_. With `RedirectToSynthesizedMethod`, Metalama generates the interceptor method from a template. A `Configure` delegate can adjust the generated method for each call site, for instance by adding parameters and type parameters.

Metalama reports LAMA1014 when the result returned for a call site can't be turned into a valid interceptor. In the message, `<Source>` is the interceptor and the aspect or fabric that registered it, `<Site>` describes the call, and `<Detail>` gives the specific problem. Typical details are:

* the `Configure` delegate adds a type parameter but doesn't give its type argument with `SetTypeArgument`, or the type argument violates the constraints of the type parameter;
* the `Configure` delegate sets a name that isn't a valid identifier;
* an added parameter receives a value both from `WithArgs` and from `SetArgument`;
* the delegate changes the type of a parameter that is passed by reference;
* the result applies to a method reference, which interceptors generated from templates don't support in this version;
* the method returned for a registration doesn't exist in the current compilation.
