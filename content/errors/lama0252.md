# LAMA0252: A template can't be partial

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `'<Declaration>' cannot be partial because it is a template.` |

## Cause

A template is a member of an aspect that Metalama compiles into code-generating code, for instance a method marked with `[Template]` or `[Introduce]`, or an override of `OverrideMethod`. Metalama doesn't support partial templates.

Metalama reports LAMA0252 on the `partial` keyword of a method, property, or indexer that's a template. When the template has a defining declaration and an implementing declaration, Metalama reports the error on both parts. The aspect class itself can be partial; only its template members can't.

In the following example, the `Describe` method introduced by the aspect is declared in one part of the aspect class and implemented in another part.

## Resolution

Remove the `partial` modifier and merge the declaration and the implementation of the template into a single member, as in the following example. You can still split the aspect class into several partial parts, as long as each template is entirely declared in one of them.
