# LAMA5104: A method name passed to [InvalidateCache] is empty

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Caching |
| **Message** | `Invalid [InvalidateCache] aspect on '<InvalidatingMethod>': the constructor parameters cannot contain a null, empty or whitespace-only string.` |

## Cause

The <xref:Metalama.Patterns.Caching.Aspects.InvalidateCacheAttribute?text=[InvalidateCache]> aspect receives, in its constructor, the names of the cached methods whose results it removes from the cache. At compile time, the aspect looks up each of these methods by name.

Metalama reports LAMA5104 when one of these names is `null`, an empty string, or a string that contains only whitespace, because such a name can't designate any method. The `<InvalidatingMethod>` placeholder is the invalidating method, that is, the method to which the aspect is applied.

In the following example, the method name passed to the aspect is empty.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5104/LAMA5104_Error.cs name="Error"]

## Resolution

Pass the name of the cached method to invalidate. Use the `nameof` operator instead of a string literal, so that the C# compiler checks that the method exists.
