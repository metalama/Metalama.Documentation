# LAMA0204: The serializable base type from a referenced project has no usable constructor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot generate a compile-time serializer for '<Type>' because the base type '<BaseType>', declared in a referenced assembly, is serializable but has neither an accessible parameterless constructor nor an accessible deserializing constructor with a single parameter of type IArgumentsReader. Add one of these constructors to '<BaseType>'.` |

## Cause

When Metalama builds the compile-time code of a project, it generates a serializer and a _deserializing constructor_, which takes a single <xref:Metalama.Framework.Serialization.IArgumentsReader> parameter, for every type that implements <xref:Metalama.Framework.Serialization.ICompileTimeSerializable> and doesn't have a manual serializer. The generated deserializing constructor must call a constructor of the base type: the base type's deserializing constructor if it has one, otherwise its parameterless constructor.

Metalama reports LAMA0204 when the type `<Type>` derives from a serializable type `<BaseType>` declared in a referenced project, and `<BaseType>` has neither a public or protected deserializing constructor nor a public or protected parameterless constructor. Because Metalama always generates a deserializing constructor for the types whose serializer it generates, this situation typically happens when `<BaseType>` has a manual serializer, that is, a nested class derived from <xref:Metalama.Framework.Serialization.ReferenceTypeSerializer>.

In the following example, the `LogCategory` class, declared in a referenced project, has a manual serializer and a single constructor, which requires a name. The `DatabaseLogCategory` class derives from it in the current project.

## Resolution

Edit the base type in the referenced project, and do one of the following:

* Add a public or protected deserializing constructor, with a single parameter of type <xref:Metalama.Framework.Serialization.IArgumentsReader>, that reads the values written by the manual serializer. The generated deserializing constructor of the derived type then calls it. Use this option when the base type has read-only state.
* Add a public or protected parameterless constructor. The generated deserializing constructor of the derived type then calls it, and the manual serializer of the base type must restore the state of the base type in its `DeserializeFields` method.
