# LAMA0207: The serializer of the base type has no parameterless constructor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot generate a compile-time serializer for '<Type>' because the serializer '<BaseTypeSerializer>' of its base type does not have a public or protected parameterless constructor. Add such a constructor to '<BaseTypeSerializer>'.` |

## Cause

When Metalama builds the compile-time code of a project, it generates a serializer for every type that implements <xref:Metalama.Framework.Serialization.ICompileTimeSerializable> and doesn't have a manual serializer. When the base type has a manual serializer, that is, a nested class derived from <xref:Metalama.Framework.Serialization.ReferenceTypeSerializer>, the generated serializer derives from it, and its constructor calls the parameterless constructor of this base serializer.

Metalama reports LAMA0207 when the base type of the serializable type `<Type>` has a manual serializer `<BaseTypeSerializer>` that has no parameterless constructor.

In the following example, the manual serializer of `LogCategory` has a single constructor, which takes the key under which the name is stored. Metalama can't generate the serializer of the derived class `DatabaseLogCategory`.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0207/LAMA0207_Error.cs name="Error"]

## Resolution

Add a public or protected parameterless constructor to the manual serializer of the base type. You can keep the other constructors.

In the following example, the serializer has a parameterless constructor that calls the other constructor with a default key.
