# LAMA0908: The exclusion predicate type must have a constructor accepting a ReferencePredicateBuilder

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Extensions.Architecture |
| **Message** | `The type assigned to the ExclusionPredicateType property must have a public constructor accepting a single parameter of type ReferencePredicateBuilder.` |

## Cause

The usage validation attributes, such as <xref:Metalama.Extensions.Architecture.Aspects.CanOnlyBeUsedFromAttribute> and <xref:Metalama.Extensions.Architecture.Aspects.CannotBeUsedFromAttribute>, and the <xref:Metalama.Extensions.Architecture.Aspects.DerivedTypesMustRespectRegexNamingConventionAttribute> attribute have an <xref:Metalama.Extensions.Architecture.Aspects.BaseUsageValidationAttribute.ExclusionPredicateType> property. It lets you exclude some references from the rule with a custom predicate: Metalama instantiates the given type and doesn't report any violation for the references that match the predicate.

Metalama creates the predicate by calling a public constructor with a single parameter of type <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicateBuilder>. A default constructor isn't enough, and neither is a constructor with additional parameters. Metalama reports LAMA0908 on the target of the attribute when the type, although derived from <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate>, has no such constructor. The attribute is then skipped: although LAMA0908 is only a warning, the whole architecture rule isn't enforced.

If the type isn't derived from <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicate>, Metalama reports <xref:lama0907?text=LAMA0907> instead.

In the following example, the constructor of `ExcludeTestTypesPredicate` has a second parameter.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0908/LAMA0908_Error.cs name="Warning"]

## Resolution

Add a public constructor whose only parameter is a <xref:Metalama.Extensions.Architecture.Predicates.ReferencePredicateBuilder> and pass it to the base constructor. If the predicate needs additional values, hard-code them or read them from another source, because Metalama can't provide them.

In the following example, the predicate excludes the references from types whose name ends with `Tests`, so `OrderTests` can use the `Order` class.
