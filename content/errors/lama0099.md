# LAMA0099: The feature isn't supported yet

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Feature is not yet supported: <Feature>` |

## Cause

LAMA0099 is a generic error meant to signal that your code uses a feature that Metalama doesn't support yet. The `<Feature>` placeholder describes the unsupported feature.

The current version of Metalama defines this diagnostic but never reports it: unsupported features are reported with more specific diagnostics. Because nothing in Metalama reports it, the article has no example.

## Resolution

If you see LAMA0099, you're probably using an older version of Metalama:

* Read the description of the feature in the message and avoid using this feature, or find another way to achieve the same result.
* Update the Metalama packages to the latest version. The feature may be supported, or reported with a more specific diagnostic.
