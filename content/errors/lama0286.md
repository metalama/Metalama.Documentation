# LAMA0286: A non-dynamic run-time expression can't be cast to IExpression

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot cast the non-dynamic run-time expression '<Expression>' to IExpression. Use ExpressionFactory.Capture.` |

## Cause

The <xref:Metalama.Framework.Code.IExpression> interface is the compile-time representation of a run-time expression. In a template, casting a `dynamic` expression to `IExpression`, for instance `(IExpression) meta.Proceed()`, is a special syntax that captures the expression. Metalama supports this syntax only for `dynamic` expressions, which can't be passed to `ExpressionFactory.Capture` because of a limitation of the C# language.

Metalama reports LAMA0286 when a template casts a run-time expression whose type isn't `dynamic` to `IExpression`. The C# cast compiles, but it can't work: the run-time value doesn't exist when the template runs, so it can't be converted to an `IExpression` object.

In the following example, the aspect casts the run-time local variable `startTime`, of type `object`, to `IExpression`.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0286/LAMA0286_Error.cs name="Error"]

## Resolution

Call `ExpressionFactory.Capture` instead of the cast. This method captures the syntax of a run-time expression into an `IExpression` without evaluating it.
