# LAMA0552: A compiler-synthesized record member can't be overridden

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<Aspect>' cannot override '<Member>' because the C# compiler adds this member to record '<Record>' unconditionally, so it cannot be declared explicitly. Override the strongly typed 'Equals' overload instead. The equality operators and 'Equals(object)' both call it.` |

## Cause

To override a member that the C# compiler generates, Metalama must declare the member explicitly in the record. The compiler generates some members of a record only when the record doesn't declare them, such as the strongly typed `Equals` overload, `GetHashCode` or `ToString`. Metalama can override these members.

The compiler, however, always adds the following members to a record, even if the record declares them, so a declaration would be a duplicate that the compiler rejects:

* `Equals(object)`;
* in a derived record, the `Equals` overload whose parameter is the base record;
* the `==` and `!=` operators.

Metalama reports LAMA0552 when an aspect tries to override one of these members, for instance by calling <xref:Metalama.Framework.Aspects.AdviserExtensions.IntroduceMethod*> with <xref:Metalama.Framework.Aspects.OverrideStrategy?text=OverrideStrategy.Override> for `Equals(object)`.
