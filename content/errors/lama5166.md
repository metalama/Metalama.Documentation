# LAMA5166: A property of a base type can't be observed

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Observability |
| **Message** | `The '<Property>' property cannot be observed because '<DeclaringType>' does not implement INotifyPropertyChanged. Consider implementing the INotifyPropertyChanged interface in '<DeclaringType>', marking '<DeclaringType>' with [Constant], or using ConfigureObservability via a fabric.` |

## Cause

The <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect updates a computed property when the properties it depends on change. For a property of a base type, the aspect relies on the base type raising the <xref:System.ComponentModel.INotifyPropertyChanged.PropertyChanged?text=PropertyChanged> event.

Metalama reports LAMA5166 when a computed property of an observable type reads a property of a base class that doesn't implement <xref:System.ComponentModel.INotifyPropertyChanged>. In the message, `<Property>` is the property of the base type and `<DeclaringType>` is the base type. The aspect can't detect changes to this property, so the computed property isn't notified.

If a computed property reads a child of another computed property of the same type, Metalama reports <xref:lama5163?text=LAMA5163> instead.

In the following example, `Greeting` reads `FirstName`, a property of the `Person` base class that isn't observable.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA5166/LAMA5166_Error.cs name="Warning"]

## Resolution

Do one of the following:

* Apply the <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect to the base type, as in the following example, or implement <xref:System.ComponentModel.INotifyPropertyChanged> in it manually.
* If you cannot change the base type, follow the other suggestions of the message: mark the property as constant, or configure the observability of the property with <xref:Metalama.Patterns.Observability.Configuration.ObservabilityExtensions.ConfigureObservability*?text=ConfigureObservability> in a fabric.
