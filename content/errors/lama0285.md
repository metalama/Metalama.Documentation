# LAMA0285: A local function in a template can't have a template or scope attribute

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The '<Attribute>' attribute is not allowed on a local function.` |

## Cause

A template can contain local functions, but they're ordinary run-time code that's part of the template's body. Metalama doesn't let you change their role with attributes.

Metalama reports LAMA0285 when a local function declared in a template has one of the following attributes:

* a template attribute, that is, an attribute that marks a member as a template or as a member to introduce, such as <xref:Metalama.Framework.Aspects.TemplateAttribute> or <xref:Metalama.Framework.Aspects.IntroduceAttribute>;
* a scope attribute, such as <xref:Metalama.Framework.Aspects.CompileTimeAttribute> or `[RunTime]`.

The `<Attribute>` placeholder is the name of the attribute type, for instance `TemplateAttribute`.

In the following example, the `Log` aspect tries to define an auxiliary template as a local function of its `OverrideMethod` template.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0285/LAMA0285_Error.cs name="Error"]

## Resolution

Depending on your intent, do one of the following:

* To reuse a piece of template code, move the local function to a method of the aspect class, mark it with `[Template]`, and call it from the template as an auxiliary template. The following example uses this approach.
* To introduce a member, declare it as a member of the aspect class with `[Introduce]`.
* To run code at compile time, move it to a compile-time method of the aspect class.
* If the local function is meant to be run-time code, remove the attribute.
