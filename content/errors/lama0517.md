# LAMA0517: The template of an interface property is missing an accessor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot implement the interface property '<InterfaceProperty>' in the type '<TargetType>' because the template '<TemplateMember>' does not have the '<AccessorKind>' accessor required by the interface property.` |

## Cause

When an aspect implements an interface with <xref:Metalama.Framework.Aspects.AdviserExtensions.ImplementInterface*>, each property of the interface is implemented by the property of the aspect that has the same name and type and is marked with <xref:Metalama.Framework.Aspects.InterfaceMemberAttribute?text=[InterfaceMember]>. This template property must have every accessor that the interface property declares.

Metalama reports LAMA0517 when the template property:

* has no `get` accessor, but the interface property has one;
* has no `set` or `init` accessor, but the interface property has one;
* has an `init` accessor, but the interface property has a `set` accessor, or the reverse.

In the message, `<AccessorKind>` is the accessor that the template is missing.

In the following example, the `ITrackable.IsChanged` property has a getter and a setter, but the template has only a getter.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0517/LAMA0517_Error.cs name="Error"]

## Resolution

Add the missing accessor to the template property, with the same kind (`set` or `init`) as in the interface property. If the property only needs to store a value, make the template an automatic property with the accessors of the interface property, as in the following example.
