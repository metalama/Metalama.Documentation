# LAMA0275: A call to a virtual template can't omit optional arguments

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The template call '<Call>' omits arguments of optional parameters, which is not supported when the called template is virtual, abstract, or an override. Specify all arguments, or make the template non-virtual.` |

## Cause

Auxiliary templates can be `virtual`, so that derived aspects can override them, and their parameters can have default values. However, Metalama currently doesn't support both at the same time: when a template calls an auxiliary template that is `virtual`, `abstract`, or a non-sealed `override`, the call must provide an argument for every parameter.

Metalama reports LAMA0275 when such a call has fewer arguments than the called template has parameters. The `<Call>` placeholder is the text of the call.

In the following example, the `Log` aspect calls the virtual `LogEntry` template without specifying its optional `verb` argument.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0275/LAMA0275_Error.cs name="Error"]

## Resolution

Do one of the following:

* Specify all arguments in the call, including those of optional parameters.
* If derived aspects don't need to override the template, remove the `virtual` modifier, or seal the overriding template, so that optional arguments can be omitted.
