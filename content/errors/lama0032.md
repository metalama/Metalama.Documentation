# LAMA0032: Several templates have the same name

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The class '<ClassName>' defines several templates named '<TemplateName>'. Template names must be unique.` |

## Cause

Metalama identifies templates by their name, for instance when you pass a template name to an advice method like `Override`. Therefore, the names of the templates of a class must be unique. Template methods can't be overloaded: two template methods with the same name are ambiguous even if their parameters are different.

Metalama reports LAMA0032 when the class `<ClassName>` defines more than one template named `<TemplateName>`. The error is reported on the second template, and the compile-time code of the project isn't built.

In the following example, the aspect defines two `Log` templates, one without parameters and one with a `category` parameter.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0032/LAMA0032_Error.cs name="Error"]

## Resolution

Give each template a unique name, and update the template names passed to the advice methods. In the following example, the second template is renamed `LogWithCategory`.
