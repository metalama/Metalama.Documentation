# LAMA5003: The non-nullable contract is redundant

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | Metalama.Patterns.Contracts |
| **Message** | `The [<AspectType>] contract on '<Declaration>' is redundant because a fabric automatically adds the [NotNull] contract to this declaration.` |

## Cause

The <xref:Metalama.Patterns.Contracts.ContractExtensions.VerifyNotNullableDeclarations*> fabric method adds the <xref:Metalama.Patterns.Contracts.NotNullAttribute> contract to the public fields, properties, and parameters of a non-nullable reference type. Metalama reports LAMA5003 when one of these declarations also has an explicit contract that the fabric makes redundant:

* a `[NotNull]` contract;
* a <xref:Metalama.Patterns.Contracts.RequiredAttribute> contract, unless the type is `string`. On a string, `[Required]` also rejects empty and white-space values, so it isn't redundant.

The explicit contract still works, so the generated code doesn't change. The warning only tells you that the attribute is unnecessary.

In the following example, the project fabric calls `VerifyNotNullableDeclarations`, and the `name` parameter also has an explicit `[NotNull]` contract.

## Resolution

Remove the explicit contract. The fabric adds the same null check, as the following example shows.
