# LAMA5110: A static method can't use caching with dependency injection

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Caching |
| **Message** | `The method '<Method>' cannot be static because caching is configured to use dependency injection, and a static method cannot access an injected dependency. Make the method non-static, or disable dependency injection by setting the UseDependencyInjection property of the [Cache] or [CachingConfiguration] attribute to false.` |

## Cause

By default, the caching aspects get the caching service, <xref:Metalama.Patterns.Caching.ICachingService>, through dependency injection: they introduce a field into the declaring type and pull it from the constructor. This field is an instance field, so a static method can't access it.

Metalama reports LAMA5110 in the following situations:

* The <xref:Metalama.Patterns.Caching.Aspects.CacheAttribute> aspect is applied to a static method, and dependency injection isn't disabled for this method.
* The <xref:Metalama.Patterns.Caching.Aspects.InvalidateCacheAttribute> aspect is applied to a static method, and at least one of the methods it invalidates uses dependency injection.

In both cases, `<Method>` is the static method. The aspect isn't applied.

When the `[Cache]` aspect is applied more than once to the same method, Metalama reports <xref:lama5112?text=LAMA5112> instead.

## Resolution

Do one of the following:

* Disable dependency injection for the method by setting the <xref:Metalama.Patterns.Caching.Aspects.CachingBaseAttribute.UseDependencyInjection> property of the <xref:Metalama.Patterns.Caching.Aspects.CacheAttribute?text=[Cache]> attribute to `false`. The aspect then uses the <xref:Metalama.Patterns.Caching.CachingService.Default?text=CachingService.Default> service.
* Disable dependency injection for a whole type or project by adding the <xref:Metalama.Patterns.Caching.Aspects.CachingConfigurationAttribute> attribute with `UseDependencyInjection = false` to the type or to the assembly, or by calling <xref:Metalama.Patterns.Caching.Aspects.Configuration.CachingConfigurationExtensions.ConfigureCaching*?text=ConfigureCaching> in a fabric.
* Make the method non-static, if the declaring type is created by your dependency injection container.

For an <xref:Metalama.Patterns.Caching.Aspects.InvalidateCacheAttribute?text=[InvalidateCache]> method, make the method non-static, or disable dependency injection for the methods it invalidates.
