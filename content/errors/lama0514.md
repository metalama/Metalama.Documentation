# LAMA0514: The target type already contains a member of the interface

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot implement the interface member '<InterfaceMember>' in the type '<TargetType>' because the type already contains '<ExistingDeclaration>', which has the same signature. Set the WhenExists property of the [InterfaceMember] attribute to Ignore or MakeExplicit, or pass OverrideStrategy.Override to ImplementInterface.` |

## Cause

When an aspect calls <xref:Metalama.Framework.Aspects.AdviserExtensions.ImplementInterface*>, Metalama introduces the members of the aspect marked with <xref:Metalama.Framework.Aspects.InterfaceMemberAttribute?text=[InterfaceMember]> into the target type. By default, these members are introduced as implicit, public implementations.

An implicit implementation can't be introduced if the target type already contains a member with the same signature. What Metalama does in this case depends on the <xref:Metalama.Framework.Aspects.InterfaceMemberAttribute.WhenExists> property of the `[InterfaceMember]` attribute. Metalama reports LAMA0514 when this property is:

* `Fail`, or
* `Default` (the default value), and the `whenExists` parameter of `ImplementInterface` isn't `OverrideStrategy.Override`. This includes `OverrideStrategy.Ignore`, which only applies when the type already implements the whole interface.

In the message, `<InterfaceMember>` is the interface member, and `<ExistingDeclaration>` is the existing member of the target type.

## Resolution

Choose how the aspect should handle the existing member:

* To use the existing member as the implementation of the interface member, set `WhenExists` to `InterfaceMemberOverrideStrategy.Ignore`. The following example uses this fix.
* To keep the existing member and introduce the template as an explicit implementation, set `WhenExists` to `InterfaceMemberOverrideStrategy.MakeExplicit`, or set <xref:Metalama.Framework.Aspects.InterfaceMemberAttribute.IsExplicit> to `true`.
* To override the existing member with the template, pass `OverrideStrategy.Override` to `ImplementInterface` and leave `WhenExists` at its default value. The existing member must be public, and also virtual if it's inherited from a base class.
* Rename or remove the existing member of the target type.
