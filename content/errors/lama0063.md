# LAMA0063: Base and current invocations are limited to members of the target type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Cannot invoke the member '<Member>' with InvokerOptions.<InvokerOption> on an explicit object or type, because '<Member>' is not a member of the template target type '<TargetType>', of its base types, or of its interfaces. Use InvokerOptions.Default or InvokerOptions.Final instead.` |

## Cause

In a template, you can invoke a member through its invoker, for instance with `IMethod.Invoke`, and choose which implementation is called with <xref:Metalama.Framework.Code.Invokers.InvokerOptions>. `InvokerOptions.Base` and `InvokerOptions.Current` select a state of the member within the aspect layers of the current type: before or after the overrides added by the current aspect layer. This only makes sense for members of the type into which the template is expanded.

Metalama reports LAMA0063 when you specify an explicit object or type with `WithObject` and use `InvokerOptions.Base` or `InvokerOptions.Current`, but the target type of the template isn't convertible to the type that declares the invoked member. In the message, `<Member>` is the invoked member, `<TargetType>` is the type into which the template is expanded, and `<InvokerOption>` is the option.

The error is reported when the template is expanded, on the declaration to which the aspect is applied.

In the following example, the `ValidateFirst` aspect overrides `OrderService.Submit` and tries to call the base implementation of `Order.Validate` on the `order` parameter.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0063/LAMA0063_Error.cs name="Error"]

## Resolution

To invoke a member of another type, use `InvokerOptions.Default` or `InvokerOptions.Final`, or don't call `WithOptions`. With an explicit object, these options call the final implementation of the member, as normal C# code would. The base or current implementation is available only for members of the target type and its base types.
