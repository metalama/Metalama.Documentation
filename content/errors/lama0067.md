# LAMA0067: A static constructor can't be invoked

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `Constructor '<Constructor>' cannot be invoked because it is static.` |

## Cause

In a template, you can generate code that creates an object by calling the `Invoke` method of an <xref:Metalama.Framework.Code.IConstructor>. Metalama then generates a `new` expression for this constructor. A static constructor, however, can't be called from C# code: the runtime runs it automatically before the type is first used.

Metalama reports LAMA0067 when a template calls `Invoke` on a static constructor. The mistake typically comes from the <xref:Metalama.Framework.Code.INamedType.StaticConstructor> property, which returns the static constructor of the type, unlike <xref:Metalama.Framework.Code.INamedType.Constructors>, which returns only the instance constructors.

In the following example, the `FactoryMethod` aspect implements a factory method by invoking the static constructor of `Counter`.
