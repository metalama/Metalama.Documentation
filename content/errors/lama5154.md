# LAMA5154: The Observable aspect doesn't support virtual properties

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Patterns.Observability |
| **Message** | `The '<Property>' <Kind> is virtual, which is not supported by the [Observable] aspect. Remove the 'virtual' modifier, or exclude the <Kind> from the aspect with the [NotObservable] attribute.` |

## Cause

The <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect rewrites the properties of the class so that their setters raise the `PropertyChanged` event, and it analyzes the dependencies between properties to notify computed properties. A derived class could override a `virtual` property with a different implementation, which would bypass the notifications and invalidate the dependency analysis. Therefore, the aspect doesn't support virtual properties.

Metalama reports LAMA5154 on each `virtual` property that the aspect processes, that is, the automatic properties of the class and the properties that other properties depend on. In the message, `<Kind>` is the kind of declaration and `<Property>` is the property.

In the following example, the `Email` property is `virtual`.

## Resolution

Do one of the following:

* Remove the `virtual` modifier, as in the following example.
* If the property doesn't need change notifications, exclude it from the aspect with the <xref:Metalama.Patterns.Observability.NotObservableAttribute?text=[NotObservable]> attribute.
