# LAMA0101: The C# language feature isn't supported in a template

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `'<Feature>' is not supported in a template.` |

## Cause

T# templates support most of the C# language, but a few constructs can't be split into compile-time and run-time parts. Metalama reports LAMA0101 when a template contains one of the following constructs, named by the placeholder of the message:

* a LINQ query expression (`from ... select ...`), reported as `LINQ`;
* a `goto` statement;
* an `unsafe` block;
* a tuple deconstruction that mixes `var` declarations with explicitly typed declarations or existing variables.

The LINQ _method_ syntax, for example `Select` and `Where` with lambdas, is supported. Only the query syntax isn't.

## Resolution

Rewrite the code without the unsupported construct:

* Replace a LINQ query expression with the equivalent LINQ method calls, as in the following example.
* Replace `goto` with structured statements such as loops, `break`, or `return`.
* Move `unsafe` code to a run-time helper method and call it from the template.
* In a tuple deconstruction, use `var` for all elements, or declare the variables before the deconstruction.
