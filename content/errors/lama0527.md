# LAMA0527: An introduced indexer can't be static

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The aspect '<AspectType>' cannot introduce the indexer '<Member>' into the type '<TargetType>' because the indexer is static. C# does not support static indexers.` |

## Cause

C# doesn't support static indexers: an indexer is always an instance member. Metalama reports LAMA0527 when an aspect introduces an indexer with the <xref:Metalama.Framework.Aspects.AdviserExtensions.IntroduceIndexer*> method and the indexer is static. This happens in the following situations:

* The aspect passes `IntroductionScope.Static` as the `scope` argument.
* The `buildIndexer` delegate sets `IsStatic` to `true`.
* The aspect uses the default scope and the accessor templates are static methods.

The error is reported on the target type.

In the following example, the `Indexer` aspect introduces the indexer with the static scope.

[!metalama-test ~/code/Metalama.Documentation.SampleCode.Errors/LAMA0527/LAMA0527_Error.cs name="Error"]

## Resolution

Introduce an instance indexer:

* Remove the `scope` argument, or pass `IntroductionScope.Instance`, and make sure that the accessor templates are instance methods.
* Don't set `IsStatic` to `true` in the `buildIndexer` delegate.
* If the target type is a static class, which can't contain an indexer, introduce a static method instead.
