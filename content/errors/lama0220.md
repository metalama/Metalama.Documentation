# LAMA0220: A template can only call template methods

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | Metalama.Framework |
| **Message** | `The template '<ReferencedDeclaration>' cannot be referenced from the template '<ReferencingDeclaration>' because it is not a method. A template can only call other templates that are methods.` |

## Cause

A T# template can reuse code from another template by calling it. These _auxiliary templates_ must be methods marked with the `[Template]` attribute. Templates of other kinds, such as properties, fields, or events marked with `[Template]`, exist to be introduced into the target type. They can't be referenced from another template.

Metalama reports LAMA0220 when a template references a template that isn't a method. In the message, `<ReferencedDeclaration>` is the referenced template and `<ReferencingDeclaration>` is the template that contains the reference.

In the following example, the `OverrideMethod` template uses the `EntryMessage` template property to compute a message.

## Resolution

Turn the reusable code into an auxiliary template method and call it as a stand-alone statement. An auxiliary template call can't be part of an expression, so move the whole statement into the auxiliary template, as in the following example.

If you only need to compute a value at compile time, use a regular compile-time method or property, without the `[Template]` attribute, instead.
