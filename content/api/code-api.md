# Code Model API documentation

These namespaces define the compile-time representation of the code model.

| Namespace                             | Description                                                                                                                                                     |
|---------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <xref:Metalama.Framework.Code>        | The root namespace representing the code model.                                                 |
| <xref:Metalama.Framework.Code.Collections> |  Contains collections for the  <xref:Metalama.Framework.Code> namespace.                                                |
| <xref:Metalama.Framework.Code.Types>        | Defines special types.                                                 |
| <xref:Metalama.Framework.Code.Comparers>        |  Contains equality and conversion comparers.                                                |
| <xref:Metalama.Framework.Code.DeclarationBuilders>  |  Defines interface that allow to build types and members. Used from introduction advice methods.                                                 |
| <xref:Metalama.Framework.Code.Invokers>        | Defines an API that allows you to generate code that access the code model at run time.                                                 |
| <xref:Metalama.Framework.Code.SyntaxBuilders>        |  Defines syntax builders and factories that allow to dynamicall create expressions and statements.                                                 |
